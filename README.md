# 📊 Sales Revenue Analysis by Product

This project reads sales transaction data from an Excel file, processes it using **Pandas**, and generates a bar plot showing **total revenue by product line** using **Matplotlib**.

## 📁 Dataset

The dataset includes order details such as:
- Quantity ordered
- Price per unit
- Product line
- Order date and location details

**Note:** The column `PRODUCTLINE` is used to group and summarize revenue.
